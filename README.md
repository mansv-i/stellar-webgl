# Stellar — Real-time WebGL Galaxy Simulation

A zero-dependency, GPU-accelerated 3D galaxy visualization rendering 250,000 interactive particles in pure WebGL 2.0. Built with custom vertex/fragment shaders, orbital mechanics, real-time mouse gravity manipulation, and procedural sound synthesis using the Web Audio API.

### Key Highlights
- **250,000 GPU Particles:** Shader-driven differential rotation and galactic arm math running at a smooth 60 FPS without external libraries (no Three.js).
- **Interactive Physics:** Real-time cursor gravity wells and click-triggered supernova shockwave propagation across the galactic plane.
- **Procedural Audio:** Built-in ambient cosmic drone and supernova acoustics synthesized via Web Audio API.
- **Cinematic Controls:** Dynamic color palettes (Cyan/Magenta, Golden Amber, Emerald Sea), camera orbit/zoom damping, and HUD photo mode toggle (`H`).
